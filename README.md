# Veterinary Clinic Dr.Ramazon

Одностраничный сайт ветеринарной клиники на Next.js, TypeScript и Tailwind CSS. Сайт собирается в готовые файлы (HTML, CSS, JS и фото) и работает на обычном хостинге без Node.js, например на Ahost.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

Готовую сборку можно посмотреть так же, как её отдаст хостинг: `npm run build`, затем `npm start`.

## Где что менять

- `src/i18n/uz.ts`, `src/i18n/ru.ts`: все тексты сайта на двух языках, включая услуги, отзывы и адрес. Узбекская версия открывается на `/`, русская на `/ru/`
- `src/content/clinic.ts`: телефоны, часы работы, координаты, соцсети, ссылки на карты
- `src/content/services.ts`: список услуг, иконки и цены
- `src/content/gallery.ts`: фотографии галереи и их порядок
- `src/components/sections`: разделы страницы
- `src/assets/images`: фотографии. При сборке скрипт `scripts/export-images.mjs` нарезает каждое фото в нескольких размерах в формате WebP, и телефон загружает маленькую копию, а компьютер большую
- `deploy/ahost`: настройки хостинга (`.htaccess`) и страница 404 на языке адреса (`404.php`). При сборке они копируются в папку `out`

## Источники изображений

- Фото доктора, пациентов и снимки в галерее взяты из соцсетей клиники.
- Четыре верхних подушечки лапы: Unsplash, лицензия Unsplash, разрешено коммерческое использование без указания автора.
- Рентген в блоке с клиническим случаем: снимок кошки из Wikimedia Commons (Radiografia-lateral-gato.jpg), общественное достояние. Это снимок другой кошки, не из описанного случая.

## Заявки с сайта

Форма открывает у посетителя Telegram с готовым текстом заявки в личном чате доктора (`telegramChat` в `src/content/clinic.ts`). Посетитель нажимает «Отправить», и заявка приходит доктору от него самого. Сервер для этого не нужен.

## Публикация на Ahost

Нужен тариф обычного хостинга на Apache или LiteSpeed с PHP. PHP используется только для страницы 404.

1. В панели Ahost привяжите домен к хостингу и выпустите бесплатный SSL-сертификат.
2. Соберите сайт с доменом и упакуйте его. В Windows PowerShell:

   ```powershell
   $env:NEXT_PUBLIC_SITE_URL = "https://ваш-домен.uz"
   npm.cmd run build
   npm.cmd run pack:ahost
   ```

   В корне проекта появится `ahost-site.zip`. Без домена архив не соберётся: иначе ссылки для поисковиков и превью в Telegram вели бы на localhost.
3. В файловом менеджере панели откройте папку сайта (обычно `public_html`). Удалите заглушку `index.html`, если хостинг её создал, а служебные папки вроде `cgi-bin` не трогайте. Загрузите `ahost-site.zip`, распакуйте его прямо в эту папку и удалите архив.
4. Проверьте: открывается главная, русская версия на `/ru/`, на несуществующем адресе появляется страница «Такой страницы нет», а форма открывает Telegram.
5. Когда сайт откроется по `https://`, включите переход на https и адрес без www: в файле `.htaccess` в корне сайта уберите знак `#` в начале пяти строк под комментарием о https.

Чтобы опубликовать правки, повторите шаги 2 и 3. Старую папку `_next` перед распаковкой можно удалить: в ней остаются только файлы прошлой сборки.

В Windows PowerShell команды нужно писать с `.cmd` (`npm.cmd`, `npx.cmd`): обычные `npm` и `npx` могут быть заблокированы политикой выполнения сценариев.
